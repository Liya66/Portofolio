TaoPiaoPiao Web Redesign

A redesign of the home page of TaoPiaoPiao, a popular Chinese movie-ticketing site, based on a usability analysis of the original.

HTMLCSSUX researchUsability analysis
GitHub Live site · coming soon

Overview

An early UX project: I analysed the usability of TaoPiaoPiao's existing site (the full write-up is in the repo), then rebuilt the home page as static HTML and CSS with a clearer hierarchy, one prominent search and consistent calls to action.

Key features

One search, clear calls to action

The hero leads with a single movie search. Featured films follow, with a consistent Get Ticket Now / Learn More pair as the next step.

Scannable listings

Movie cards share one structure: a still, a two-line synopsis and one action. Reviews and upcoming releases follow further down the page.
