Overview

A full-stack photo-sharing app modelled on Pinterest and filled with my own photography. Visitors browse an infinite masonry feed and search by title, description or tag. Signed-in users publish pins, organise them into boards, comment, like, save and follow other users.

The React client gets server state from TanStack React Query and keeps local UI state in small Zustand stores. The Express API authenticates with a JWT in an httpOnly cookie. Images go through Sharp on the server before upload to ImageKit, which serves resized versions to the feed.

Key features

Infinite masonry feed with search

The feed uses useInfiniteQuery against a cursor-paginated endpoint (21 pins per page) and loops back to the start once every pin has been shown. The same endpoint handles case-insensitive search across titles, descriptions and tags, and filters by user or board.

Pin pages with comments and interactions

Each pin shows its author, a comment thread with an emoji picker and relative timestamps, and like/save actions. A separate interaction-check endpoint tells the client whether the current user has already liked or saved the pin, so the buttons render in the right state.

In-browser image editor

Before publishing, users can open the photo in an editor: add a text layer with size and colour, switch orientation, choose an aspect ratio and set a background colour. The server then burns the text into the image with Sharp before uploading it to ImageKit.

Create, board and profile flows

Pins have a title, description, link, tags and board. A new board can be created from the same form. Profiles show a user's created and saved pins, follower counts and a follow button, and a settings page edits the display name and avatar.
